# Eco Route

## Назначение
Eco Route — приложение Streamlit на Python для оценки CO₂ поездки
и сравнения видов транспорта. Пользовательский интерфейс — на литовском.
Объяснения разработчику по умолчанию — на русском.

## Текущее устройство
- app.py: литовский интерфейс Streamlit и состояние пользовательской сессии.
- eco_route/calculations.py: единицы, коэффициенты и чистые расчёты CO₂e.
- eco_route/geoapify.py: сетевые запросы, валидация, кэш сессии и лимит запросов.
- eco_route/journey.py: сбор расстояний и сохранение частичного успеха.
- eco_route/presentation.py: спецификация графика Vega-Lite с расстояниями в подсказках.
- eco_route/rail.py: локальный поиск прямых поездок по календарям VINTRA.
- data/lithuanian_rail.json: открытый снимок LTG Link, геометрия и расписания; CC BY 4.0.
- tools/import_lithuanian_rail.py: воспроизводимый импорт железнодорожного подмножества GTFS.
- requirements.txt: прямые зависимости; requirements.lock: закреплённое дерево.
- .streamlit/secrets.toml: локальные секреты; не включать в Git.
- .streamlit/secrets.example.toml: только заглушка для настройки ключа.
- docs/roadmap.md: порядок работ и критерии готовности.
- docs/methodology.md: источники, границы расчёта и научные ограничения.
- data/emission_factors_2026.json: действующие коэффициенты и идентификаторы источников.
- tools/verify_factors.py: повторная сверка с официальным XLSX без сети.
- .devcontainer/devcontainer.json: Python 3.11 и запуск Codespaces.
- tests/: unittest и Streamlit AppTest; запросы к сети подменяются.
- .github/workflows/tests.yml: тесты Python 3.11/3.13 и аудит зависимостей.
- Базы данных и авторизации нет.
- Git подключён к blackrubik/eco_route; локальный app.py отличается от main на GitHub.

- Не добавлять зависимости без конкретной необходимости.

- Не менять литовские подписи на другой язык без запроса.

- Не отключать защиты Streamlit CORS и XSRF в конфигурации запуска.

## Секреты и внешние сервисы
- Получать GEOAPIFY_API_KEY через настройки секретов Streamlit.
- Не выводить ключ и полный URL с apiKey в сообщения, логи или тесты.
- Не добавлять secrets.toml в Git; примеры содержат только заглушки.
- В автоматических тестах подменять Geoapify подготовленными ответами.
- Реальные запросы с ключом выполнять только в согласованной проверке.
- Обрабатывать отсутствие ключа, тайм-ауты, HTTP-ошибки,
  пустые результаты и неожиданную структуру ответа.

## Координаты и расстояния
- GeoJSON возвращает координаты как longitude, latitude.
- Внутри проекта явно соблюдать выбранный порядок координат.
- waypoints Geoapify в текущем формате использует latitude,longitude.
- Проверять единицы расстояния; внутри расчётов использовать километры.
- Не выдавать геодезическое расстояние за дорожный или железнодорожный путь.
- Профиль bus не подтверждает наличие пассажирского рейса.
- Получать координаты один раз для сравниваемой поездки.

## Расчёт CO₂
- У каждого коэффициента должны быть единицы, источник и допущения.
- Различать г/км транспортного средства и г/пассажиро-км.
- Делить на число людей только коэффициент на транспортное средство.
- Проверять неотрицательные конечные расстояния и положительное
  целое число участников.
- Одинаково применять допущения к выбранному транспорту и альтернативам.
- Оценки для деревьев обозначать как условную иллюстрацию.
- Не возвращать неподтверждённые пороги «вреда» и обещания компенсации деревьями.
- Для авиационных коэффициентов DESNZ не применять повторно уже включённые
  поправки расстояния и RF. Британские средние явно отличать от данных Литвы.
- При неполных данных всегда показывать ограничение сравнения.
- Блок «Neįtraukti variantai» показывать только для ошибок или отсутствия данных;
  превышение предела ходьбы/велосипеда в этот блок не включать.
- Сбой альтернативы не должен скрывать успешный основной результат.
- Сначала искать прямую железнодорожную поездку в снимке VINTRA между ближайшими
  станциями (не далее 8 км); применять календарь и исключения даты. Снимок старше
  30 дней не использовать как действующее расписание. Длина — по опубликованной
  геометрии, время — между станциями, без ожидания и подвоза.
- При отсутствии подходящей поездки сохранять оценку дуга большого круга × 1.35
  по Barret (2020), с меткой ≈; не рисовать для неё вымышленную линию по рельсам.
- Брать первое найденное место и сразу рассчитывать, без отдельного подтверждения.
- Число людей показывать и учитывать только при выбранном автомобиле.
  При другом выборе автомобильная альтернатива рассчитывается для одного человека.
- RF включён по умолчанию; пределы альтернатив: ходьба 10 км, велосипед 35 км.
  Не возвращать блок настройки этих параметров и дублирующую график таблицу.
- Объяснения коэффициентов, происхождения данных и расписаний держать в раскрываемом
  блоке методики; приблизительные расстояния явно помечать на графике и в результате.
- Карта показывает найденные точки и полученную геометрию маршрута.
  Для самолёта рисовать приблизительную дугу большого круга между точками
  с соответствующей подписью; она не является фактической траекторией рейса.
  Время Geoapify — модель; GTFS — расписание без ожидания; неизвестное время
  не превращать в ноль и не подменять выдуманной средней скоростью.
- Не возвращать таблицу: сравнение времени и CO₂e размещать во вкладках графика.
- Не заменять коэффициенты выбросов корпоративными Scope 1/2 или Scope 1/2/3
  без проверки распределения на пассажиро-км и совместимости с WTT.
- Режим «Žinomas atstumas»: сравнение одинакового расстояния для всех
  видов транспорта, а не обещание одинаковой длины реальных путей.
- Кэш адресов хранить только в сессии; глобально разрешены лимит запросов
  без адресов и общедоступные данные коэффициентов и железнодорожного снимка.

## Проверки
- Проверять формулы, единицы и граничные значения правил.
- Проверять отсутствие маршрута, ошибки API и частичный успех.
- Проверять сохранение результатов при взаимодействии с интерфейсом.
- До появления тестов явно сообщать, какие проверки выполнены вручную.
- Не считать проверку синтаксиса доказательством работоспособности приложения.
- Основная команда: .venv/bin/python -B -m unittest discover -s tests -v.
- Проверка исходных чисел: python3 -B tools/verify_factors.py /path/to/factors.xlsx.
- AppTest проверяет поведение и данные графика; не выдавать его за визуальную
  проверку браузера или проверку реальных маршрутов.
- После изменения импортов или интерфейса Python-модулей перезапускать локальный
  Streamlit перед передачей просмотра пользователю. Проверять выполнение скрипта
  на работающем сервере: ответ /_stcore/health не проверяет импорт и загрузку UI.
