# Проверки версии от 15 ноября 2026 года

## Среда

- macOS, CPython 3.13.2, отдельное `.venv`; системные пакеты не изменялись.
- Streamlit 1.67.0, Geopy 2.5.0, Requests 2.34.2, pip 26.3.
- Полное дерево из 35 библиотек закреплено в requirements.lock.
- Python 3.11 локально отсутствует. Для него проверены синтаксис, доступность
  зависимостей и известные уязвимости, но не выполнение приложения.
- GitHub Actions подготовлен на Python 3.11/3.13, но удалённо ещё не запускался.

## Выполненные проверки

- `python -B -m unittest discover -s tests -v`: 49 тестов. Известные примеры CO₂e,
  число участников, авиационные поправки, отрицательные/нечисловые/бесконечные
  значения, ограничения расстояния и расчёт сценарной экономии.
- Клиент API: координаты и единицы, пустой/повреждённый JSON, неожиданные поля,
  тайм-ауты, HTTP 3xx/400/401/403/429/5xx, отсутствие повторов после 429,
  большой ответ, исчерпание времени, изоляция кэша и лимит запросов.
- Streamlit AppTest: запуск без секретов, ручной расчёт, нулевое расстояние,
  изменение числа людей, сохранение/устаревание/очистка результата, первый найденный
  результат без подтверждения, расчёт поезда без ручного ввода и частичный сбой.
  Дополнительно проверены скрытие числа людей для другого транспорта, применение
  одного человека к автомобильной альтернативе, неизменные настройки по умолчанию,
  отсутствие таблицы и сброс результатов старой версии после смены метода.
- Схема Vega-Lite проверена библиотекой Altair; данные графика проверяют тесты:
  ноль сохраняется, отсутствие данных не заменяется нулём, выбор помечается,
  приблизительный поезд получает ≈, расстояния доступны в подсказках.
- `pip check`: несовместимых установленных зависимостей нет.
- Установка requirements.lock без сети подтвердила соответствие локальной среде.
- Инструмент `verify_factors.py` подтвердил 10 строк официального XLSX DESNZ:
  значения, единицы, идентификаторы и SHA256 совпали.
- pip-audit 2.10.1, база PyPI: после обновления Geopy и pip не найдены известные
  уязвимости среди 36 пакетов окружения (включая pip). Отдельно проверен список
  для Python 3.11 с NumPy 2.4.6 — известных уязвимостей также не найдено.
  Это результат на дату проверки, а не гарантия отсутствия любых ошибок.
- Локальный сервер Streamlit запущен на 127.0.0.1:8505; `/_stcore/health` отвечает `ok`.
- После обнаруженного ImportError при обновлении модулей сервер полностью
  перезапущен. Дополнительно проверено реальное выполнение начального экрана через
  локальный WebSocket: скрипт завершился, получены элементы интерфейса, исключений
  нет. Это проверка исполнения UI на сервере, а не визуального отображения браузера.
- `git diff --check`: замечаний к форматированию изменённых отслеживаемых файлов нет.

## Что не проверялось

- Реальный Geoapify с пользовательским ключом: все сетевые ответы в тестах подменены.
- Отображение на телефоне и с экранным диктором.
- Реальное выполнение под Python 3.11, Linux, Codespaces и удалённым CI.
- Публичный хостинг, нагрузка нескольких процессов и наличие реальных рейсов.

Ключ не выводился, внешние сообщения не отправлялись. Commit, push и deployment
не выполнялись. Данные API-квоты пользователя при автоматических тестах не расходовались.

## Карта, время и VINTRA

Добавлены проверки GeoJSON, порядка координат, сохранения расстояния при ошибке
времени/геометрии, общего кэша маршрутного ответа, охвата обеих точек картой,
вкладки времени, календарных исключений и устаревшего снимка. Поездки Вильнюс—Каунас
и Вильнюс—Клайпеда проверяются на фиксированной дате 2026-11-15, без сети.
Схема графика времени проверена Altair. Дополнительно выполнена визуальная
проверка в изолированном headless Chrome при 1280×1100: подложка CARTO/OSM,
точки A/B, железнодорожная линия и вкладка времени отобразились. Проверка использует
подменённый Geoapify и настоящий открытый снимок VINTRA; это не проверка реального
дорожного API. Обнаруженная ошибка единиц размеров Pydeck исправлена, и тест
проверяет сериализацию строковых единиц pixels, чтобы она не повторилась.
Приблизительная линия самолёта дополнительно проверена в Chrome на тестовом
направлении Вильнюс—Лондон: дуга и точки A/B отображаются, подпись уточняет её
характер. Основной сервер после перезапуска загружает интерфейс без ImportError.
