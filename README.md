# Eco Route

Streamlit-приложение для приблизительной оценки CO₂e поездки и сравнения
транспортных сценариев. Интерфейс — на литовском языке. Репозиторий:
https://github.com/blackrubik/eco_route

## Возможности

- Выбросы на человека за поездку в одну сторону по проверенным DESNZ 2026.
- Число людей учитывается для автомобиля; общественный транспорт повторно
  на число попутчиков не делится.
- «Žinomas atstumas»: сравнение одного расстояния без ключа и сетевых запросов.
- Первое найденное Geoapify место используется сразу, без подтверждения; дорожные профили
  ходьбы, велосипеда, автомобиля и местного автобуса.
- График с расстояниями в подсказках, возможная экономия и объяснение исходных чисел.
- Карта найденных точек и полученного пути, время рядом с CO₂e и вкладка сравнения времени.
- Для прямых поездов LTG Link — линии и время между станциями из VINTRA;
  при отсутствии подходящих данных сохраняется приблизительная оценка.
- Частичный результат при ошибках, сохранение результата и отметка устаревших настроек.

Методика: [docs/methodology.md](docs/methodology.md). Оставшиеся задачи:
[docs/roadmap.md](docs/roadmap.md). Проверки: [docs/validation.md](docs/validation.md).

## Запуск

Целевые версии Python — 3.11 и 3.13; Codespaces использует 3.11.
Локальные тесты выполнены на 3.13.2. В терминале из корня проекта:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pip==26.3
python -m pip install -r requirements.lock
python -m streamlit run app.py
```

Быстрая проверка: «Žinomas atstumas», 100 км, автомобиль, один человек,
кнопка «Apskaičiuoti». Ожидаемый результат — **20.99 кг CO₂e**.

Для поиска мест создать `.streamlit/secrets.toml` по образцу
`.streamlit/secrets.example.toml` и добавить свой `GEOAPIFY_API_KEY`.
Существующий файл с ключом не перезаписывать. На хостинге использовать Secrets.
Без ключа ручной режим и страница продолжают работать.

## Структура

| Файл | Назначение |
|---|---|
| `app.py` | Интерфейс и состояние сессии |
| `eco_route/calculations.py` | Коэффициенты, единицы и чистые расчёты |
| `eco_route/geoapify.py` | Сетевой клиент, проверка ответов, кэш и лимиты |
| `eco_route/journey.py` | Сбор расстояний с сохранением частичного результата |
| `eco_route/presentation.py` | Графики CO₂e/времени и карта |
| `eco_route/rail.py` | Поиск прямого поезда по календарям VINTRA |
| `data/lithuanian_rail.json` | Открытый снимок станций, геометрий и расписаний |
| `tools/import_lithuanian_rail.py` | Обновление железнодорожного снимка |
| `data/emission_factors_2026.json` | Коэффициенты, единицы и идентификаторы источников |
| `tools/verify_factors.py` | Повторная сверка с официальным XLSX |
| `tests/` | unittest и Streamlit AppTest без реального API |

`requirements.txt` фиксирует прямые зависимости; `requirements.lock` — дерево
для Python 3.11/3.13 на macOS/Linux с отдельными версиями NumPy. Эти файлы
обновляются вместе, после тестов и аудита. pip обновляется отдельной командой.

## Приватность и нагрузка

Названия мест и координаты передаются в Geoapify. Ключ, адреса и полный URL
с `apiKey` нельзя записывать в Git, сообщения и журналы. Кэш только в памяти
своей сессии: до 128 записей, поиск до 24 часов, маршруты до 6 часов.
В ключе кэша используется отпечаток секрета. Кнопка очистки удаляет данные сессии.

Один расчёт по местам требует до шести HTTP-запросов: два поиска и до четырёх
дорожных профилей. Поезд оценивается автоматически без дополнительного запроса. Кэш сокращает их количество. Повторов нет; после 401/403/429
новые запросы в операции прекращаются. Лимит — 30 запросов в минуту на процесс
и 5 секунд между сетевыми действиями сессии. Для нескольких процессов нужен
внешний общий ограничитель. API-клиент не использует `.netrc`, прокси окружения
и перенаправления.

Бюджет операции — 25 секунд с проверкой до запроса и при чтении. Тайм-ауты
подключения/чтения — до 3/6 секунд, размер ответа — до 2 МБ. Это не строгий
предел общего ожидания: DNS и сетевой стек могут увеличить время.

## Проверки и публикация

```sh
.venv/bin/python -B -m unittest discover -s tests -v
.venv/bin/python -m pip check
python3 -B tools/verify_factors.py /path/to/official-factors.xlsx
```

GitHub Actions подготовлен для тестов и аудита на Python 3.11/3.13; workflow
запустится после push. Codespaces устанавливает зависимости и показывает
порт 8501. CORS/XSRF включены. Сам контейнер и удалённый CI пока не запускались.
Публичный хостинг не настроен. Commit, push и публикация — отдельные действия.

## Границы достоверности

Коэффициенты преимущественно британские, не специфичные для Литвы. Суммируются
эксплуатация и опубликованная составляющая WTT; это не полный жизненный цикл.
Поезд оценивается автоматически: дуга большого круга между найденными точками
× 1.35 (метод Barret, 2020), если нет подходящего прямого поезда в VINTRA.
Для найденного поезда длина берётся по линии, время — по расписанию между станциями,
без ожидания и подвоза. Снимок требует обновления через 30 дней. Самолёт между найденными точками — сценарий
без аэропортов, подвоза и пересадок. Наличие рейсов не проверяется. Автобус —
местный, не междугородний. Нули для ходьбы и обычного велосипеда относятся только
к обозначенным границам. Показатели «вреда» и компенсации деревьями удалены.

Литовские данные, обновление и проверка местных коэффициентов: [docs/local-data.md](docs/local-data.md).
